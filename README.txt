안약 기록 PWA v0.4

APK / Android Studio / Family Link 외부 APK 설치가 필요 없는 웹앱입니다.

구성: index.html, app.js, manifest.webmanifest, sw.js, icon.svg

실행 및 설치
1) 폴더를 HTTPS 웹 호스팅(예: GitHub Pages, Netlify)에 통째로 게시합니다.
2) 갤럭시 S22의 Chrome에서 게시한 HTTPS 주소를 엽니다.
3) Chrome 메뉴(점 3개) > 홈 화면에 추가 또는 앱 설치를 선택합니다.
4) 홈 화면 아이콘으로 실행합니다. 최초 방문 뒤에는 캐시된 파일로 오프라인 실행 가능합니다.

주의: 파일 탐색기에서 index.html을 직접 열면 PWA 설치와 오프라인 기능이 정상 작동하지 않습니다.
웹 호스팅 주소는 이 ZIP만으로 자동 생성되지 않습니다.
기록은 브라우저 localStorage에 기기별로 저장됩니다. 기기 간 동기화/백업이 없고 브라우저 데이터 삭제 시 소실될 수 있습니다.
알림 기능은 없습니다.

초기 일정은 이전 안드로이드 v0.3 예시를 반영했습니다:
A/B/C 시작일 2026-11-07, A/B 06:30,12:00,17:00,21:00, C 06:30,21:00.
왼쪽 눈 내원 2026-11-10 08:00, 오른쪽 눈 2026-11-11 11:00.
D는 각 내원 60분 전과 30분 전.
이 값은 예시이며 실제 처방과 반드시 대조하고 설정에서 수정하세요.
