안약 기록 앱 v1.9 — 권한 분리 및 실시간 동기화 안정화
====================================================

변경 사항
1. 어머니 A33: 설정 탭 표시 안 함, 앱에서도 설정 저장 차단.
2. 보호자 아이폰: 설정 변경 가능, 완료 체크는 보기 전용.
3. Firestore 규칙에서도 어머니 계정의 설정 변경을 차단. 어머니는 보호자 연결 승인만 가능.
4. 실시간 리스너 유지 + 포그라운드 복귀/인터넷 복구 시 서버에서 최신 데이터 확인.
5. 앱을 열어둔 동안 30초 간격으로 서버 최신 상태 재검증. 서버 연결이 없으면 상태에 알림.
6. v1.8과 같은 기록 키, 같은 가족 ID/로그인 역할/기존 대기열 사용. 데이터 초기화 금지.
7. 디쿠아스, 수술 완료, 기존 모든 점안 시간표는 변경하지 않음.

★ 업데이트 순서 (두 군데 모두 반드시 업데이트)
A. 기존 GitHub에 게시된 정상 firebase-config.js를 준비하여 이 폴더의 REPLACE_ME 파일과 교체.
B. ZIP 파일의 firestore.rules를 Firebase 콘솔 > Firestore Database > 규칙에 붙여넣고 게시.
C. index.html, app.js, cloud.js, sw.js, manifest.webmanifest, icon.svg, firebase-config.js를 GitHub Pages 저장소의 최상위에 업로드, Commit.
D. 아이폰/A33에서 v1.9 확인. 기존 앱 삭제나 사이트 데이터/기록 삭제는 금지.
E. 아이폰에서 설정 수정 후 A33에 반영되는지, A33에서 완료 체크 후 아이폰에 자동 반영되는지 테스트.
F. 네트워크 복구 및 백그라운드 복귀는 각각 30초 이내 또는 자동 재동기화 확인. 완전한 즉시 반영은 연결 상태에 따라 보장되지 않음.

★ 중요: Firestore 보안 규칙을 적용하지 않으면 A33의 설정 변경을 서버에서 실질적으로 차단할 수 없습니다.
규칙이 먼저 배포된 잠깐 동안 기존 v1.8의 A33 설정 저장이 실패할 수 있습니다. 정상입니다.
현재 v1.8에서 이전에 A33이 설정 변경을 시도해 대기 중인 설정은 v1.9에서 자동 삭제됩니다.
기존 점안 기록은 삭제되지 않습니다.

★ Firebase 설정키를 다시 공개 채팅에 입력할 필요는 없습니다. v1.8에서 사용하던 구성 파일을 복사하세요.
의료 지시는 병원 처방이 우선이며 앱은 기록용이고 알림 기능은 없습니다.
