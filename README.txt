effectiveAt은 이전 것보다 늦은 YYYY-MM-DDTHH:MM:SS로 입력하세요. 기존 과거 체크 상태는 변경하지 않습니다.

휴대폰 체크 기록은 localStorage에만 저장됩니다. 사이트 데이터 삭제/재설치 시 기록이 사라질 수 있습니다.
앱이 오프라인이면 마지막으로 성공적으로 내려받은 스케줄을 유지합니다.
2026-11-12 이후에는 최신 처방을 꼭 확인해야 합니다. 앱은 별도 알림이 없는 점안 기록 도구입니다.
