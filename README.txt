안약 기록 앱 v1.8 — 동기화 안정화
================================

[중요: Firebase 설정 파일 반드시 유지]
이 압축파일의 firebase-config.js에는 REPLACE_ME가 들어 있습니다.
이미 v1.7을 GitHub Pages에 배포하고 Firebase 연결 정보를 설정했다면,
현재 사용 중인 v1.7의 'firebase-config.js'를 이 v1.8 폴더에 복사하여 교체하세요.
그렇지 않고 이 ZIP의 기본 파일을 그대로 올리면 클라우드 연결이 작동하지 않습니다.

만약 수정된 firebase-config.js 파일을 잃어버렸다면, Firebase 콘솔 → 프로젝트 설정 → 일반 → 내 앱 → 웹 앱 → 구성에서 설정값을 다시 확인하여 입력할 수 있습니다.
서비스 계정 비밀키, 비밀번호는 앱에 저장하지 마세요.

주요 변경사항
- 디쿠아스에스: 11월 10일 왼쪽 수술 당일, 11월 11일 오른쪽 수술 당일에도 표시
- 디쿠아스에스 종료일: 왼쪽/오른쪽 각각 설정 가능 (기본 양쪽 2026-11-11)
- '기록' 하단 탭 제거. 이전 점안 체크 데이터는 삭제하지 않음
- 기존 날짜 선택은 '오늘' 화면에 남겨둠
- A33 최초 연결 시 기존 체크 기록 누락 여부를 서버와 비교해 재전송
- '☁ 연결' 화면에 '현재 기기 기록 백업'과 '기존 기록 업로드 확인·재시도' 추가
- 네트워크가 끊겼을 때 기록과 설정 변경을 로컬에 대기시키고 재연결시 재전송 시도
- 동기화 상태를 화면에 표시, 보호자 모드는 완료 체크 읽기 전용
- 기존 로컬 저장키 유지: eyedrop-record-pwa-v06

GitHub 업로드
1. ZIP 압축을 풉니다.
2. 이 폴더의 firebase-config.js를 기존 v1.7에서 설정한 정상 파일로 반드시 교체합니다.
3. GitHub Pages 저장소 루트에 index.html, app.js, cloud.js, firebase-config.js, sw.js, manifest.webmanifest, icon.svg를 업로드하고 Commit changes 합니다.
4. PC/아이폰에서 v1.8이 표시되는지 확인합니다.
5. A33은 기존 앱 삭제, 저장소 초기화, 사이트 데이터 삭제 금지. 동일 주소/브라우저로 들어가 기존 체크가 보이는지 확인합니다.
6. 최초 클라우드 연결 전 ☁ 연결 → 현재 기기 기록 백업을 실행하여 JSON 백업을 보관합니다.
7. A33에서 ☁ 연결 → 어머니 기기 연결 시작을 누르고 전송 확인 상태를 점검합니다.
8. 아이폰의 보호자 로그인으로 표시되는 UID를 A33에 입력해 승인 후, A33의 UID를 아이폰에 입력하여 가족 데이터와 체크 결과를 확인합니다.

클라우드 보안
Firestore 규칙은 firestore.rules 파일을 Firebase 콘솔의 Firestore → 규칙에 게시해야 합니다.
규칙 적용만으로 권한 테스트가 완료된 것은 아닙니다. 실제 두 기기의 읽기/쓰기 권한을 확인하세요.
현재 Firestore 규칙 설계: 어머니 기기 기록 쓰기, 승인된 보호자 읽기 및 설정 쓰기.
Firebase API 키는 웹 앱 구성용 공개 키지만 Firestore 접근 제한은 보안 규칙에 의존합니다.

중요: 이 앱은 의료적 처방을 대신하지 않습니다. 안내문 및 담당 의료진의 최신 지시가 우선입니다.
수술 중/후 안약 D의 점안 시간과 디쿠아스 종료일, 수술 후 A/B/C 일정은 병원에서 확인한 대로 설정해 주세요.
점안 알림은 제공되지 않으며 브라우저 저장공간 삭제 시 로컬 기록이 사라질 수 있습니다.
