안약 기록 앱 v1.6 — GitHub Pages 설치용 PWA (알림 없음)

변경 사항
- 디쿠아스: 2026-10-14부터 각 눈의 수술 전날까지 하루 6회(07:30,10:00,12:30,15:00,17:30,20:00)
- 각 눈의 수술 당일부터는 해당 눈의 디쿠아스 일정 자동 제외; 다른 눈은 수술 전이라면 일정 유지
- 설정에서 디쿠아스 일정 ON/OFF 선택 가능
- 모든 안약 사이의 기본 간격 10분(5~10분 정수 입력 가능); A/B/C 시간차에 반영
- 최소 간격보다 가까운 다른 안약 일정은 눈별 충돌 목록에 표시; 자동 변경하지 않음
- D 시작/종료 규칙은 기존 버전과 동일. D 점안 시간은 병원 처방으로 재확인 필요
- 기존 기록 localStorage 키 유지: eyedrop-record-pwa-v06

설치: 압축을 풀어 모든 파일을 GitHub Pages 저장소 루트에 업로드하고 Commit changes.
기록은 사용 중인 브라우저/기기에만 보관되며 다른 기기로 자동 동기화되지 않습니다.

수술 후 관리: 눈별 수술 완료 날짜·시간, 첫 점안 재개 시각, 1시간 간격 종료 시각 설정. 수술 완료 시 D 중지, A/B는 당일 1시간→2시간, 이후 매일 2시간 간격, C는 하루 두 번. 실제 점안 지시는 병원 안내 우선.

변경 사항: 같은 안약·같은 점안 시각은 좌우 눈을 한 행에 표시합니다. 눈별 저장 식별자는 이전 버전과 동일하게 유지합니다.
